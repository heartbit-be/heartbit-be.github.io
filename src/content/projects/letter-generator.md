## From a font to a physical letter

A typeface starts as outlines on a screen. Making those outlines into a printable object brings a different set of questions: thickness, holes, shape, and how the layers fit together.

This project explores that boundary through a generator that turns letters into 3D models.

## The work

The tool brings together font processing, mesh construction, and checks on the generated geometry. A preview makes the result easier to inspect before exporting it for printing.

It is a meeting point for two parts of Heartbit: writing software and making physical things.
