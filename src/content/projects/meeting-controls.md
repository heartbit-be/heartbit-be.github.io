## Small tools for familiar tasks

During a meeting, finding a control should not take your attention away from the conversation.

This project connects Stream Deck buttons to Microsoft Teams controls on macOS, exploring a more direct way to use actions that would otherwise need a trip through the interface.

## The work

The software connects the plugin interface with macOS accessibility controls. That involves translating a button press into an action in another application, and dealing with changes in the interface along the way.

A focused tool, built around an everyday interaction.
